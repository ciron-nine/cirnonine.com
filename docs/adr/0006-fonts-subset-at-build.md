# 字体按页面实际用字在构建时切片

外壳用四种字体，每种管一类文字：正文（思源黑体 Noto Sans SC）、我的声音（霞鹜文楷）、我的声音里的日文（Klee One，和文楷同一母本）、作品的日文原名和日文语录原文（Shippori Mincho）。哪段文字归哪种字体由页面结构决定：在 `.voice` 里的是我的声音，在 `lang="ja"` 里的是日文。

构建完成后读出每一页 HTML，按这个规则分出每种字体要显示的字，从 npm 包里的完整字体切出子集，再按「出现在多少页上」切成每片 60 个字的 woff2，写成带 `unicode-range` 的 `/fonts/faces.css`。浏览器只下载当前页面用到的几片，换页时已经下过的片走缓存。

首页原型 D 里正文也用霞鹜文楷。这里有意不同：正文改用黑体，我的声音才能在每一页上一眼认出来，不和作品资料、界面文字混在一起（站长确认）。

## Considered Options

- **现成的切片字体包**（lxgw-wenkai-screen-webfont、Fontsource）：按通用字频切成上百片。实测本站每页要下 0.5–1.4 MB，因为一页上几十个字会散落在几十片里。
- **按全站字符做一个子集文件**：现在每种字体 50–80 KB，但会随长评增多一直变大，首屏下载跟着涨。
- **按页切子集**：每页最省，但换页时字体文件全换，会闪，也用不上缓存。

## Consequences

- 一页要下载的字体在几十 KB：没有长评的首页约 13 KB，列出全部记录的类别页约 70–80 KB。`tests/site-content.test.ts` 用保守算法守着每页 120 KB 的上限。
- 霞鹜文楷用的是 TC 版：npm 上只有它有完整字体文件。它收了全部简体字，共用的字按台湾字形；逗号、句号、顿号在 TC 版里居中，改借 Klee One 靠左下的那几个（`roles.ts` 的 `handOff`）。
- 原名全是汉字的日文作品（群青、千本桜）看不出语言，记录里要写 `lang: ja`；带假名的自动识别。
- 与 ADR-0002 冲突，值得修订：ADR-0002 只允许各类别共享与外观无关的部分，但我的声音（`src/components/voice/` 和 `voice.css`）是带外观、跨类别共用的组件。这是 ADR-0005「我的声音在每一页都用同一种排版」的直接要求，ADR-0002 应该把我的声音列为唯一的例外；共用的只限这五样，不扩展成通用的记录组件。
- 字体名和回退顺序写在 `src/fonts/roles.ts`，Shell 和 `voice.css` 里的 `font-family` 要和它一致。类别页和专属页的标题字体（作品的声音）不走这套，按各自的设计另做。
- 用 JS 往页面里塞的文字，只有在全站某一页上以同一种字体出现过才有字形（例如「点播中」的歌名就来自音乐页）。
