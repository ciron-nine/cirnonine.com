# 外壳统一，内容区自由；专属页按需制作

所有页面共享同一个外壳（站标、导航、播放器与静音、页面转场、正文字体），外壳之内的内容区可以完全按自己的风格设计。任何记录都可以按需拥有一个专属页：它是单独编写的页面，有自己的版式、标题字效和背景音乐，而不是通用模板加参数。

## Consequences

整站的统一感只靠外壳维持，所以外壳要保持克制，不要往里塞某个类别的风格。专属页不是每条记录都有：没有专属页的记录留在类别页里，用类别的默认设计。每新增一个专属页都是一次独立的设计工作。

**强度梯度**：外壳最安静，类别页适中，专属页最强烈。WebGL 等重特效只用于首页主视觉和专属页，否则专属页就显不出特别。
