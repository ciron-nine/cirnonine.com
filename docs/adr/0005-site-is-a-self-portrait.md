# 网站是我的自画像，作品是构成我的材料

这个网站要展现的是我，作品之所以出现，是因为我把时间花在了它们身上。每一页都同时有两种声音：作品的声音（封面、从封面提取的颜色、原名）和我的声音（短评、长评、我挑的语录、心头好、完成日期）。我的声音在每一页都用同一种排版呈现，它才是整站统一感的真正来源。

## Considered Options

- **统一视觉母题**（游戏卡带/主机、冰与碎片、⑨）：被否决，它们把设计压进一个狭窄的比喻里，而且表达的不是我。
- **作品为主角、网站只做中性策展**：被否决，这样网站里就没有我了。

## Consequences

- 我的声音的气质是安静、克制、私人、带一点粗粝（日记、专辑内页、后朋克的黑白、中西部情绪摇滚的颗粒感），这份气质只约束我的声音和外壳；作品的颜色仍来自作品本身。
- 很多记录年代久远，日期和感受已不可考：完成日期可以只到月、只到年或"很久以前"，短评可以不写。只有封面和原名的记录也必须好看。
